# UI_MAP.md — Spravoshnik EPB v1.2

## 1. Назначение

Документ фиксирует карту пользовательского интерфейса, основные экраны, вкладки и переходы.

Главное правило UI:
- глобальное меню содержит только глобальные рабочие разделы;
- вложенные сущности открываются в контексте организации, ОПО, договора или экспертизы;
- документы не имеют отдельного глобального рабочего раздела.

# 23. Регистрация в РТН

Вкладка:

```text

Попытка №2
...
```

Для каждой:
- состояние;
- дата отправки;
- решение;
- номер реестра;
- дата регистрации;
- документы;
- история статусов.

После создания следующей попытки предыдущая становится исторической и недоступна для обычного изменения бизнес-результата.

Действия:
- подготовить пакет;
- отметить отправленным;
- внести результат;
- создать новую попытку после отказа.

---

# 37. Общие UI-правила

1. Не дублировать одну сущность в нескольких глобальных меню.
2. Основные действия доступны в шапке карточки.
3. Опасные действия требуют подтверждения.
4. Пользователь не видит физические пути файлов.
5. Недоступные действия скрываются, но backend всё равно проверяет permission.
6. Статусы показываются единообразно.
7. Просроченность выделяется отдельно от статуса.
8. Ошибки бизнес-правил объясняются понятным текстом.
